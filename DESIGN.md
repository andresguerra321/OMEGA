# OMEGA Desktop Design System (`DESIGN.md`)

## 1. Visual World & Product Character
**Minimalist Negro · Blanco · Azul Rey Security Instrument** — inspired by tactile spatial hardware interfaces and serene atmospheric security consoles (`atmosphere-background` × `dark-blue-contrasting-clean` × `mesh-gradient-dark-blue-clean`). Contrasts a deep obsidian-navy `#050811` canvas with drifting royal-blue (`#1D4ED8` / `#2563EB`) vertical light folds (`SecurityPostureStage.jsx`) on the left against a curved (`rounded-l-[28px]`) sculpted architectural alabaster-white inspector sheet (`#F5F7FB`) on `Inicio`, transitioning seamlessly to a high-contrast dark obsidian workbench sheet (`.roam-obsidian-sheet`, `#090D16` → `#05070C`) for deep forensic investigation modules.

## 2. Shell & Navigation Architecture (`App.jsx` + `electron/main.js`)
- **Zero generic left sidebar, stacked bottom dock, or cartographic map metaphors:** Navigation lives inside a floating frosted dark circular icon capsule (`SpatialNavPill.jsx`, `aria-label="Navegación espacial OMEGA"`), pinned top-center over the left atmospheric reception canvas on `Inicio` and centered inside the 52px instrument bar on specialized views. Active destination highlights in crisp pure white (`#FFFFFF`) with `#090D16` foreground and live LED indicators (`pcVerdict`, `usbConnected`, `apiOnline`, `isLoadingChat`).
- **Dual Spatial Split (`Inicio`):**
  - **Left Pane (`SecurityPostureStage.jsx`, `56%–60%` desktop width):** `#050811` canvas with volumetric vertical light curtains purely in Azul Rey (`#1D4ED8` / `#2563EB`) and deep sapphire (`#172554`) over black (hinting crimson on the corner edge only under confirmed alert), continuous top/bottom vignette, architectural inset framing (`border-[#93C5FD]/[0.05]`), `OMEGA` wordmark, zero-kicker editorial security posture statement, four interactive hairline-bordered protection surfaces (`#01 Esta PC · Windows`, `#02 Celular por USB`, `#03 Escudo de enlaces`, `#04 Base forense STIX2`) synced with the right inspector with `#3B82F6` active indicator bar, top-right `RefreshCw` / `SlidersHorizontal` triggers, and bottom-left volatile RAM guarantee (`Memoria volátil · 0 bytes en disco`).
  - **Right Curved Sheet (`OverviewWarmInspector.jsx`, `.roam-stone-sheet`, `#F5F7FB`):** Curved left border seam (`rounded-l-[28px]`) with interactive vertical seam collapse/expand toggle pill, pure white search pill (`⌘K`), circular alert/Copiloto bell button (`Bell` + `#1D4ED8` count badge), global `Simple | Técnico` toggle, context-reactive matte-black & royal-blue vector illustration directly on `#F5F7FB`, overlapping `#FFFFFF` elevated structured summary card (`Lectura` / `Estado actual` grid + primary `#1D4ED8` Azul Rey CTA + inline quick link verify), and high-contrast dark cards (`.roam-dark-strip`, `#0D1322` → `#070A12`) under `Últimos análisis` (`PC Windows · RAM y WMI`, `USB Móvil`, `Firmas STIX2`, `Verificador pasivo de enlaces`).
- **Specialized Workbench Modules (`equipo`, `enlace`, `amenazas`, `exposicion`, `preguntar`, `ajustes`):**
  - Left stage narrows on `xl` screens (`27%`, `max-w-[360px]`) into a serene compact ambient rail showing the four hairline protection rows (collapsible via the vertical seam grabber button) while the right sheet transitions cleanly into `.roam-obsidian-sheet` (`#090D16` → `#05070C`) hosting the interactive dark-mode workbenches with zero contrast loss.
- **Dynamic Native Electron TitleBar (`electron/main.js` + `preload.cjs`):** `titleBarStyle: 'hidden'` + dynamic `omega:set-titlebar-theme` IPC overlay syncing Windows `- □ ✕` chrome seamlessly between light alabaster (`#F5F7FB` / `#090D16`, `height: 40`) on `Inicio` and obsidian (`#090D16` / `#A1A7B4`, `height: 40`) on all other modules, with `pt-11` / `pr-40` caption clearance when `isDesktop` is true.
- **Non-destructive Slide-Over Copilot (`CopilotDrawer.jsx`):** Slides in at `max-w-[470px]` over any active view (`pt-9` desktop clearance under `- □ ✕`) with pinned context support, preserving underlying scans or audits on dismiss (`Escape` or backdrop click).

## 3. Surfaces, Elevation & Color Roles (`index.css`)
- **Atmospheric Stage Ground:** `#050811` near-black radial ambient depth + `#070B15` (`omega-stage-bg`) with crisp `#F8FAFC` wordmark, `<canvas>` Azul Rey vertical light folds, and `rgba(147, 197, 253, 0.08)` hairline details.
- **Architectural Light Inspector (`.roam-stone-sheet`):** `#F5F7FB` alabaster-white primary shell paired with crisp `#FFFFFF` elevated cards (`.roam-white-card`), inverted dark-navy `#070A12` strip blocks (`.roam-dark-strip` with subtle `rgba(59, 130, 246, 0.16)` border), high-contrast `#090D16` ink, `#475569` secondary metadata, and Azul Rey `#1D4ED8` / `#2563EB` focal accents.
- **Obsidian Workbench Sheet (`.roam-obsidian-sheet`):** `#090D16` → `#05070C` gradient with hairline left border `rgba(255,255,255,0.08)`, molded dark surfaces (`.apple-group`), and recessed telemetry wells (`.apple-well`).
- **Semantic Status Accents:**
  - Brand Focal / Royal Blue (Azul Rey): `#1D4ED8` / `#2563EB` / `#3B82F6`
  - Verified / Clean: `#16A34A` / `#22C55E`
  - High Risk / Alert: `#DC2626` / `#EF4444`

## 4. Typography & Clarity Modes
- **UI Sans (`Inter`):** Clean editorial contrast with `-0.025em` display tracking (`Esta PC — Windows`, `Últimos análisis`) and readable Spanish copy.
- **Technical Mono (`JetBrains Mono`, `.font-tech`):** Applied strictly to live sensor counts, CVEs, hashes, URLs, timestamps, and keycap hints (`⌘K`, `ESC`, `RAM`).
- **Global `Simple` / `Técnico` Toggle:** Available directly on both the `Inicio` stone header and the dark obsidian header; switches seamlessly between everyday Spanish clarity and technical telemetry (`sockets`, `hits YARA`, raw verdicts).

## 5. Tactile Controls & Accessibility
- Physical press feedback, explicit keyboard navigation (`⌘K`, `Ctrl+J`, `Esc`), semantic landmarks (`<section aria-label="Postura de seguridad OMEGA">`, `<aside aria-label="Panel inspector de protección">`, `<nav aria-label="Navegación espacial OMEGA">`, `<main>`), WCAG AA focus rings (`2px` `#191C22` on stone, `#5E9BFF` on dark), and complete `@media (prefers-reduced-motion: reduce)` guards.
